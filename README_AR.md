# تطبيق حضور التلاميذ QR

## بنية ملفات الويب
يجب أن يكون ملف الصفحة الرئيسية في المسار `www/index.html` لأن إعداد Capacitor يحدد `webDir` بالقيمة `www`.

## البناء
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub، مع الحفاظ على مجلد `www`.
2. تأكد من وجود ملف `www/index.html`.
3. شغّل GitHub Actions لبناء APK.

أوامر البناء المحلية:
```bash
npm install
npx cap sync android
npx cap open android
```

## الوظائف الموجودة في الصفحة
- إضافة التلاميذ والبحث والتصفية حسب القسم.
- توليد QR لكل تلميذ وطباعة رمز تلميذ واحد أو رموز التلاميذ المحددين فقط؛ لا يوجد زر لطباعة QR لجميع التلاميذ دفعة واحدة.
- تسجيل الحضور بالكاميرا أو يدوياً، مع منع تكرار تسجيل الطالب في اليوم نفسه.
- تصدير سجل الحضور ولائحة التلاميذ إلى XLSX، مع CSV احتياطي عند عدم توفر مكتبة XLSX.
- استيراد ملفات Excel/CSV.
- إنشاء واسترجاع نسخة JSON احتياطية.
- حفظ محلي للبيانات على الجهاز.

## تنبيهات مهمة
- يعتمد مسح QR وتوليد QR ومكتبة Excel على مكتبات CDN؛ يلزم اتصال بالإنترنت لتحميلها ما لم تُضمّن محلياً.
- بيانات `localStorage` مرتبطة بتثبيت التطبيق والجهاز. احتفظ بنسخة JSON خارجية دورياً.
- يلزم اختبار إذن الكاميرا والطباعة على جهاز Android بعد بناء APK. لا تعتبر هذه النسخة معتمدة قبل الاختبار الفعلي.

## أيقونة التطبيق التي تظهر عند التثبيت
- الأيقونة المعتمدة موجودة في `assets/icon.png` (1024×1024)، ونسخة الأيقونة التكيفية في `assets/icon-foreground.png`. سيولّد سير البناء ملفات أيقونات Android (بما فيها أيقونات المشغّل التكيفية) قبل إنشاء APK.
- بعد تثبيت الاعتماديات وإنشاء مجلد Android بواسطة `npx cap add android` (إن لم يكن موجوداً)، نفّذ:
  ```bash
  npm install
  npm run icons:generate
  npx cap sync android
  ```
- افتح المشروع في Android Studio ثم ابنِ APK. ستظهر الأيقونة الجديدة بجانب اسم التطبيق في شاشة الهاتف وقائمة التطبيقات بعد تثبيت النسخة الجديدة.


## إنشاء APK عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى المستودع على GitHub، مع وضع مجلد `.github` في جذر المستودع.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Android APK** ثم اضغط **Run workflow**.
4. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل وحمّل الملف من قسم **Artifacts** باسم `attendance-qr-debug-apk`.
5. فك ضغط ملف Artifact ثم ثبّت `app-debug.apk` على هاتف Android.

يُنشئ سير العمل مشروع Android، ويولّد أيقونة التطبيق التي تظهر في شاشة التثبيت وقائمة التطبيقات، ثم يبني APK تجريبياً (Debug). يلزم اتصال بالإنترنت أثناء البناء. لا يمكن تثبيت APK جديد فوق إصدار سابق إذا كان موقّعاً بمفتاح مختلف إلا بعد إزالة الإصدار السابق؛ انتبه إلى أخذ نسخة احتياطية من البيانات أولاً.
